# Romance Genre Memory Rules

## Mandatory Standards

- Relationship state must track current status, attraction, trust, conflict, intimacy, and unresolved wounds.
- Emotional beat sheets must define intended reader emotion, trigger, character choice, and state transition.
- Character behavior must be motivated by established wounds, desire, fear, or plot pressure.
- Ending direction and central couple contract require author approval.
- Tension changes must be explainable from previous state.

## Anti-Patterns

- Sudden affection, betrayal, or forgiveness with no state transition.
- Using misunderstanding as a conflict without character grounding.
- Resolving core tension too early without a replacement tension.
- Changing HEA/HFN expectations midstream without approval.
