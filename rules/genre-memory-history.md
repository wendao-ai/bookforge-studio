# History Genre Memory Rules

## Mandatory Standards

- Source entries must include citation, source type, date, origin, credibility, bias notes, and usage scope.
- Timeline entries must include date precision and source basis.
- Historiography statements must identify viewpoint, disputed interpretations, and excluded claims.
- Critical historical claims require source support and confidence labels.
- Conflicting sources must be represented rather than erased.

## Anti-Patterns

- Writing historical claims without source trace.
- Treating a disputed interpretation as uncontested fact.
- Mixing narrative speculation with sourced claims without labels.
- Changing chronology for drama without marking it as fictionalization.
