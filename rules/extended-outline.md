# Extended Outline Rules

## Mandatory Standards

- Each chapter plan must define purpose, inputs, outputs, scene/section beats, dependencies, memory updates, and review gates.
- Genre-specific requirements must be explicit: reveals for scifi, prerequisites for textbook, emotional beats for romance, sources for history.
- Each chapter must name what it promises the reader and what it withholds.
- Structural risks must be logged before drafting.
- Drafting may begin only when the target chapter has an approved plan.

## Anti-Patterns

- Writing prose directly from a top-level outline.
- Creating chapter plans with no dependency or memory-update fields.
- Treating all genres as chapter-summary-only workflows.
- Forgetting to update registry files when a chapter introduces a new promise or concept.
