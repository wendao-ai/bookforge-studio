# 第一性原理方法论（First-Principles Method）

> **不可违反原则**：任何调研判断前，先做问题降维 + 原理拆解，禁止现象层结论。
> 这是本 skill 与"行业报告复读机""资料堆砌"的根本区别。
> 本文件是 deep-topic-research SKILL 原则 1 的操作手册。

---

## 1. 为什么需要第一性原理

**反例**：看到"市场规模 3 万亿"就判断"这本书值得写/这个赛道值得进"——这是现象驱动决策。市场大 ≠ 你的书能切到差异化角度，≠ 论点站得住。

**正例**：先问"这个赛道的价值创造原理是什么、现有书都停在哪一层、读者真正的认知缺口在哪"（降维到原理层），再决定本书的核心论点——这是本质驱动决策。

第一性原理的核心动作：**后退一步，从问题的表层陈述，逐层拆到不可再分的底层原理，再基于原理重新定义问题**。

| 维度 | 现象层思考 | 第一性原理思考 |
|------|----------|--------------|
| 问什么 | "怎么讲 X 更好" | "X 的本质是什么，为什么需要 X" |
| 深度 | 描述 / 比较 | 原理 / 规律 / 终局 |
| 时效 | 易过时 | 长期有效 |
| 用途 | 了解 | 决策 / 立论 |

---

## 2. 五段流程（问题降维 → 原理拆解 → 重构）

本 skill 的 Step 1 完整跑这五段，产出"调研方向树"。

### Stage P1：问题降维（Problem Decomposition）

把主题的表层陈述逐层往下拆，直到触及"原子约束"（不可再分的基本约束单元）。

**隐含假设挖掘**（每个表层主题至少藏 2 个假设）：

- **形态挑战**：作者说"写一本关于 X 的书"——挑战"为什么必须是 X 这种形态的书"，拆出读者真正的功能需求（学什么 / 解决什么 / 获得什么洞察）
- **约束挑战**：识别约束层级，判断能否挑战：
  - L0 物理定律（不可违反）
  - L1 材料/理论极限（可突破）
  - L2 工程取舍（可挑战）
  - L3 用户习惯（可挑战）
  - L4 法规标准（需评估）
- **正交拆分**：把混合需求拆成独立维度（如"全面性" vs "可操作性"，"深度" vs "易读性"）

**递归追问话术**（5-Why 原理化版本，问"为什么这是约束"）：

```
表层 → 功能层："读者的具体哪个认知/能力不达标？"
功能层 → 约束层："什么在阻止他们达标？"
约束层 → 物理层："这个约束的本质是什么？"
物理层 → 原理层："这是本征限制还是工程/认知限制？"
原理层 → 原子层："根本矛盾是什么？"
```

**原子约束判定**（四条全满足）：单一学科 / 可量化 / 不可再分 / 非对称依赖。

### Stage P1.5：普遍性评估（Universality Assessment）

评估每个原子约束的**跨领域普遍性**——这决定主题的价值等级与本书的受众宽度。

**三轴评估**：

| 轴 | 问什么 | 评分 |
|----|--------|------|
| 行业/领域轴 | 这个原理在哪些领域也成立？ | A(≥5) / B(3-4) / C(2) / D(1) |
| 场景轴 | 在什么使用场景下出现？ | 同上 |
| 方法轴 | 可用多少种不同方法/视角阐释？ | 同上 |

**综合等级**：三轴均衡加权，A 级原理（跨 3+ 领域/场景/视角）优先深挖——它既是本书差异化论点的富矿，也是读者的最大认知收益。

**反虚高**：同名现象 ≠ 同一原理。"效率"在制造业/软件/医疗若底层机制完全不同，不应合并成一个论点。

### Stage P2：原理拆解（Principle Extraction）

为每个原子约束识别底层原理，并标注要注入的前沿知识。

**原理表述三段式**（禁止用现象词当原理）：
```
学科 + 机制 + 指标
合格：认知科学·工作记忆容量受组块化限制，决定一次性可处理的概念数
不合格：读者记不住（这是现象）
```

**原理深度等级**：
- D0 表面（只描述现象）
- D1 功能（识别功能维度）
- D2 学科（识别学科原理）← 本 skill 最低门槛
- D3 定律（精确到核心方程/规律）
- D4 极限（识别理论上限/终局）

**知识注入**（每个原理至少覆盖三类知识角色，详见 knowledge-sources-protocol.md）：
- 前沿边界（全球最新做到哪 / 该领域研究前沿）
- 成熟迁移（别的领域/学科有无成熟阐释或方法）
- 方向约束（趋势/标准/共识是否支持这个原理）

### Stage P3：问题重构（Problem Reframing）

基于原子约束 + 底层原理，重新提出"更好的核心论点/角度"。这一步直接决定本书的 `uniqueness_anchor`。

**五种重构模式**：

| 模式 | 一句话 | 适用条件 |
|------|--------|---------|
| A 升维重构 | 多个约束统一到一个原理框架 | 一个原理关联 ≥2 个读者痛点 |
| B 替代原理 | 换一个底层原理绕过认知瓶颈 | 存在替代原理解释同一现象 |
| C 跨域迁移 | 把别的领域的成熟阐释迁过来 | 有高质量迁移假设 |
| D 矛盾消解 | 让对立需求各自满足 | 两个约束存在 trade-off |
| E 尺度跃迁 | 改变分析尺度（微观/宏观） | 有尺度相关发现 |

**重构候选语法**（必须是"好论点/好角度"，不是章节标题）：
```
本书主张：在 [读者真实约束] 下，
通过 [底层原理/替代视角]，
让读者 [核心认知收益] 而 [避开现有书的盲区]。
```

**质量门**：≥ 2 个候选，每个有 why_better 论证 + universality_score + reframe_mode，交作者选择。

### Stage P4：上溯回流（Upward Reflection）

站在重构后的更高维度回看原主题，决定动作：

- **修改**：原主题替换为重构后角度
- **保留+新增**：两者都做（主论点 + 补充视角）
- **替换**：原主题是伪需求，放弃
- **拆分**：原主题拆成多本书或多个核心论点
- **暂停**：信息不足，补调研（回到 Step 2）

## 3. 在写书调研中的应用

第一性原理不是只在"定主题"时用——**为本书每个核心论点建调研方向时都要用**：

- **核心论点（thesis）**：直接跑五段流程，把作者初步想法拆到原子原理，判断"这个论点站不站得住、有没有更深的讲法"
- **读者承诺 / uniqueness_anchor**：用 P3 重构模式识别"现有书都停在 D0-D1，本书能否讲到 D2-D3"——这是差异化的本质来源
- **概念树（concept_tree）**：用 P1 正交拆分把主题拆成独立概念维度，每个维度对应一个调研方向（KnowledgeRequest）
- **章节论断**：草稿期引用本 skill 产出的 source-note 时，每条论断要能追溯到某个原理的 D2+ 表述

**与第一性原理的对照自检**（每个调研方向都要能回答）：
- 这个方向的底层原理是什么（学科+机制+指标）？
- 它对应读者哪个原子约束？
- 它的普遍性等级（A/B/C/D）？
- 现有书讲到哪一层（D0-D4）？本书要讲到哪一层？

---

## 4. 红线

- ❌ 用现象词（"体验差""效率低""市场大"）当结论或论点
- ❌ 不挖隐含假设就接受作者的表层主题
- ❌ 拆不到原子约束就下判断
- ❌ 原理表述缺指标（无法量化验证）
- ❌ 只沿现有书的原理框架，不找替代原理/替代视角
- ❌ 跨域迁移不标 confidence（尺度/环境/成本/成熟度四项检验）
