# Biography Pack Knowledge

传记类型知识库。本 Pack 的方法由跨 genre 共享能力层承载 + 传记专属增量。

## 方法索引

见 `method-catalog.yaml`。

## 传记专属增量（fiction-general 没有）

1. **事实-叙事分离** — 每段叙事可追溯 fact_basis；重构显式标注（critical）。
2. **传主伦理边界** — 授权/隐私/在世人物法律风险/敏感事件（critical 人审）。
3. **多源记忆交叉验证** — 访谈/档案/第三方回忆矛盾保留，不抹平。
4. **人生阶段-叙事权重** — turning 阶段权重最高，word_budget 体现。
